# VFitDiary

**Track. Transform. Become. 💪**

VFitDiary is a full-stack fitness tracking platform designed to help users plan workouts, track training sessions, monitor body composition, visualize progress, and maintain workout streaks.

The application uses **React + TypeScript** for the frontend, **Spring Boot + Java** for the backend, and **MySQL** for persistent data storage.

---
### 🚀 Live Demo
👉 [VFitDiary](https://vfit-diary.vercel.app/)

## ✨ Features

### 🔐 Authentication

- User registration and login
- JWT-based authentication
- Access-token and refresh-token handling
- Secure logout functionality

### 📊 Dashboard

- Fitness overview
- Current progress
- Workout information
- Streak information

### 📏 Body Assessment

- BMI calculation
- BMR calculation
- Daily calorie estimation
- Body-fat percentage assessment

### 🏋️ Workout Generator

- Push / Pull / Legs
- Upper / Lower
- Full Body
- Structured workout plans

### 📝 Workout Tracker

- Log exercises and sets
- Track weights and repetitions
- Automatic 1RM estimation
- Personal record tracking

### 📈 Progress Tracking

- Weight progress
- Training volume
- Personal records
- Progress charts

### 📅 Workout Calendar

- Workout history
- Monthly calendar
- Streak tracking
- Workout heatmap

### ⚙️ User Settings

- Profile management
- Theme settings
- Account controls

### 🛡️ Secure Backend

- Spring Security
- JWT authentication
- REST APIs
- JPA / Hibernate
- MySQL database
